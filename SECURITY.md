# Security Policy

## Reporting a Vulnerability

Thank you for helping us maintain the security of Manifest. If you discover a security issue, we appreciate your responsible disclosure.

This repository is a fork. Report vulnerabilities in **this fork's** code here, so
they reach the people who can actually patch it — sending fork-specific issues
upstream both delays the fix and discloses them to a third party:

[Submit Security Issue](https://github.com/dariusta/manifest/security/advisories/new)

If you have confirmed the issue also reproduces on unmodified upstream Manifest,
please additionally report it to [mnfst/manifest](https://github.com/mnfst/manifest/security/advisories/new).

Please provide as much detail as possible, including steps to reproduce the issue, potential impact, and any additional context.

Thank you,
The Manifest team
